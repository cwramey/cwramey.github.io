Project overview

The problem

Geodatabase schemas are hard to review, edit, and share without desktop GIS software, which slows handoffs and keeps nontechnical collaborators out of the process.

The solution

A client-side editor makes the schema portable, validates changes in the browser, and connects to a matching ArcGIS Pro toolbox only for the final binary build.

Capabilities

Make a schema portable

Import widely

Accepts JSON, XLSX, XML Workspace, GeoPackage, and zipped geodatabases.

Edit safely

Review feature classes, fields, domains, subtypes, and nullability with validation.

Use real presets

Start from Fiber, Small Cell, Gas Line, or Field Inspection network models.

Round-trip to Pro

Pairs browser JSON with an ArcPy toolbox for create and export operations.

Fiber Route Analyzer ↗

GIS Developer  ·  2025

Problem

Fiber permitting requires identifying every road, rail, water, bridge, and pipeline crossing along a proposed route. The process was manual, error-prone, and impossible to repeat quickly across multiple route alternatives.

Approach

Built a Streamlit app that ingests KML, KMZ, GeoJSON, and Shapefile routes, detects crossing conflicts against live ArcGIS FeatureSever layers (with retry/backoff and TTL cache), classifies risk by crossing type, and generates permit corridor polygons with city, county, road name, and confidence scores.

Outcome

Delivers operator-ready exports including KMZ, Shapefiles, Markdown report, and an Excel workbook with data quality sheets, enabling permit prep that previously took days to complete in a single session. Shareable snapshot links support run replay and stakeholder review.

Python Streamlit GeoPandas ArcGIS FeatureServer KML/KMZ Shapefile
★ Automated multi-layer conflict detection across roads, rail, water, bridges, gas/oil pipelines, and parcels, with risk-classified permit corridors exported in one click

Permit PDF Analyzer ↗

GIS Developer  ·  2025

Problem

Reviewing telecom design PDFs to extract fiber and duct measurements, count poles, and calculate total route footage was a slow, error-prone manual process repeated across every permit submission.

Approach

Built a Streamlit app backed by a FastAPI/Netlify Functions serverless handler that parses multi-page design PDFs using PyMuPDF block-level extraction. A four-strategy fallback engine (summary footer, station-chain, E-LASH span, callout span) automatically selects the best parsing method per sheet while filtering out legend and title block contamination.

Outcome

Extracts total footage, pole count, per-segment spans, and the logic path used, all surfaced in a live-progress UI with an expandable JSON debug view. Reduces per-permit measurement review from manual calculation to seconds.

Python PyMuPDF Streamlit FastAPI Netlify Functions
★ Automated fiber/duct measurement extraction from telecom design PDFs using a four-strategy parser, eliminating manual permit review calculations

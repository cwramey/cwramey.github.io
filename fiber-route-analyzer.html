Project overview

The problem

Permit reviewers spent hours visually checking long fiber corridors against roads, rail, waterways, bridges, pipelines, and parcel data.

The solution

One analysis run ingests the route, detects and deduplicates crossings, classifies risk, and builds a package the field and permitting teams can use immediately.

90%reduction in permit-review time
15k+miles of utility corridors processed
1operator-ready export bundle

Capabilities

From route file to permit package

Flexible inputs

Reads KML, KMZ, GeoJSON, and Shapefile route files with CRS normalization.

Conflict intelligence

Checks live ArcGIS FeatureServer layers and classifies each crossing by risk.

Corridor context

Builds permit corridors with city, county, road-name, and confidence metadata.

Usable exports

Produces KMZ, Shapefiles, Excel, and a Markdown summary for follow-up work.

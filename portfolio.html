GIS  ·  Permitting

Fiber Route Conflict Analyzer

Ingests KML, KMZ, GeoJSON, and Shapefile routes and detects every crossing conflict against live ArcGIS FeatureServer layers, classifies risk by crossing type, and generates permit corridor polygons tagged with city, county, road name, and a confidence score. Delivers operator-ready exports and cuts permit prep from 2–3 days of manual map review to under an hour.

Highlights

  • Reads KML, KMZ, GeoJSON, and Shapefile route inputs
  • Detects crossings against roads, rail, water, bridges, gas/oil pipelines, and parcels from live ArcGIS FeatureServer layers
  • Classifies each conflict by crossing type and assigns a confidence score
  • Generates permit corridor polygons tagged with city, county, and road name
  • Exports operator-ready KMZ, Shapefiles, a Markdown report, and an Excel workbook

AI  ·  PDF Parsing  ·  Telecom

Design PDF Analyzer

Turns unstructured telecom design PDFs into clean, queryable data, extracting fiber footage, duct measurements, and pole counts with PyMuPDF, text search, and regex. Cuts per-permit review from 20–30 minutes of manual counting to under 30 seconds per sheet.

Highlights

  • Reads the text layer of design PDFs directly with PyMuPDF (no OCR needed for vector exports)
  • Extracts linear fiber footage, duct counts, sizes, and materials, and pole counts
  • Counts unique entities to avoid double-counting poles across overlapping sheets
  • Uses text position to recover values when the PDF's reading order is jumbled
  • Emits structured JSON ready for a downstream API or spreadsheet

GIS  ·  Geodatabase  ·  Schema

ArcGIS GDB Schema Tool

A browser-based tool to import, edit, and build ArcGIS geodatabase schemas with no ArcGIS Pro required, paired with a matching ArcGIS Pro Python toolbox for the create/export round-trip. Parses JSON, Excel, XML Workspace, GeoPackage, and .gdb.zip files entirely client-side, so schema never leaves your machine.

Highlights

  • Imports schema from JSON, Excel, XML Workspace, GeoPackage, and .gdb.zip, all parsed in the browser
  • Review and edit feature classes, fields, domains, and subtypes with live validation
  • Four built-in infrastructure presets: Fiber, Small Cell, Gas Line, and Field Inspection
  • ArcGIS Pro Python toolbox to create a geodatabase from a preset and export an existing one back to JSON
  • Styled Excel template round-trip for non-technical schema authoring
